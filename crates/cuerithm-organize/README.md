# Read-only organization planning

This crate defines a deliberately limited naming language and a full-scope immutable preview. It performs no filesystem I/O, mutation, provider request or native DJ database update. The library organization coordinator remains responsible for capturing/revalidating native authority, identities, content hashes and revisions, journal recovery and no-replace publication. A serialized preview is evidence, never an authorization capability supplied by a frontend.

## Naming grammar

Use `{title}`, `{artist}` (first nonblank), `{artists}` (all nonblank, comma separated), `{album}`, `{album_artist}`, `{album_artists}`, `{genre}`, `{genres}`, `{label}`, `{version}`, `{release_date}`, `{year}`, `{key}`, `{bpm}`, `{energy}`, `{track}`, `{disc}`, `{original_name}` and `{parent}`. `original_name` is a stem, not a complete filename; `parent` is one parent component, not an absolute path. Values come from final effective metadata. Date precision and key notation are supplied by that context without inventing missing values. `{year}` extracts only a known four-digit year; `{bpm}` uses a positive integer hundredths value supplied by the accepted analysis/context and renders two decimals for the filename only. `{energy}` accepts the existing whole-track 1–10 scale; neither token changes analysis. Invalid zero tempo/out-of-range energy blocks even when organization is optional.

Example: `{artists}/{track|pad:2} - {title}[ ({version})]`. `|upper` and `|lower` apply Unicode case conversion. Only numeric track/disc accept `|pad:1` through `|pad:8`. One nonnested `[optional segment]` is omitted only with `OmitOptional` and a missing token in that segment. Optional segments cannot include directory separators. There is no escape syntax, arbitrary expression evaluation, regex execution, upstream alias support or claim of OneTagger grammar parity. Patterns are bounded at 2,048 bytes.

The pattern names the stem and optional subdirectories. The original native source extension is appended, including when the title already contains a dot. Metadata control characters and `/\<>:"|?*` become underscores; final literal text is validated rather than repaired. Empty names, traversal, absolute/drive paths, reserved device names, trailing spaces/dots, oversized components and paths always block. Portable rules are the default caller choice; `Unix` permits Unix-specific final names but cannot bypass the portable template-literal grammar. `SkipOptional` only skips missing metadata when organization is explicitly optional, never a required operation or an unsafe name.

## Snapshot and publication contract

Supply complete `PlanInput`: final metadata and revisions for every selected track, SHA-256/size/native identity/path revision for each source and owned sidecar, root identity, required reference revisions, hashed existing destination files and non-file occupancy (directories, symlinks and other entries). Capture every potentially relevant existing destination and ancestor through the trusted native layer. The planner automatically adds selected source/sidecar paths to occupancy; existing paths outside selection must be supplied. Incomplete snapshots cannot prove absence and must not be accepted by the native coordinator.

NFC plus Unicode lowercase reservations conservatively reject composed/decomposed and ordinary case collisions across the entire selected scope, including sidecars. This is not a replacement for the actual volume's equivalence, hard-link, symlink/reparse and no-follow checks. Alias targets remain blocked; the planner does not promise a case-only rename. Same-path unchanged rows require the source snapshot. Existing-copy no-ops require exact destination path, equal SHA-256 and byte count; their destination evidence is retained. Directory targets and symlink/non-directory ancestors block.

Native paths serialize as ordinary strings when representable; otherwise raw Unix bytes or Windows UTF16 units are retained and decoding on another OS is rejected. Non-Unicode parent components are preserved; a source extension that cannot be represented for validated generated naming blocks.

Completed rows sort by stable track ID; `page` bounds each response to 1,000 rows and `totals` distinguishes all outcomes. The digest covers the complete original input including configuration, source, metadata, destination inventory, sidecars and references; `matches_inputs` invalidates changes, including input order changes. Cancellation returns an error without a partial completed preview. Native code must still recapture/revalidate inputs and hold its own operation identity before mutation; hashes do not eliminate TOCTOU races. `can_apply` permits the ready subset of a fully completed preview, with blocked/skipped rows remaining explicit.
