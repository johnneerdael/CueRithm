## How the app shows these values

- **Cue names.** The player, the cue buttons and sync use the saved names **Start**, **Drop**,
  **Breakdown**, **Drop #2**, **Breakdown #2** and **End / Fade-out**. The analysis data
  stores the detector names Second Drop, Second Breakdown and Last beat; they appear only as
  hover text in the table's PREVIEW column. The Cues column below uses the saved names.
- **BPM** is shown with two decimals (130.00); the table below gives whole numbers.
- **Energy** is one whole-track rating from 1 to 10, shown as 6/10. There is no energy per cue.
- **Duration** is shown as m:ss and can differ from the Length column by a second because the
  table rounds.
- **Playlists** the screenshots will use are in `ia.md` ("Demo library"). Corrections from the
  Playlists writer: *Added this week* is an ordinary smart playlist with the rule `Date added`
  is in the last 7 days (not an automatic smart playlist); *Mixes with 7A* is `Key is
  compatible with key 7A` in Harmonic mode (6A, 7A, 8A and 7B); *Warm-up set* holds, in this
  order, When The Fire Starts To Burn, Palm Of Your Hands, Desert, F*ck The Club, Murda, Shake
  The Block, Underground and Atoma.
