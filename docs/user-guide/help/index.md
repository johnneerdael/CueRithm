# Get help

<p class="lead">Find the symptom you see, read the answer to a common question, check what CueRithm does not do yet, or report a problem. Most fixes take under ten minutes.</p>

## Start here { #start-here }

Not sure what is wrong? Match what you see on screen in the table below. Each row opens a page that explains the cause, gives the steps, and shows how to check that the fix worked. If nothing matches, read the [Frequently asked questions](faq.md), then [report the problem](report-a-problem.md).

## What are you seeing? { #what-are-you-seeing }

| What you see | Page |
|---|---|
| A dash in the **PREVIEW** column, or a track that will not play | [A track shows a dash or will not play](troubleshooting/no-waveform-or-playback.md) |
| More tracks than files, titles twice, tracks marked **Missing** after you moved or renamed files | [I moved or renamed my files](troubleshooting/files-moved.md) |
| A track that stays in Incoming, or *N need attention* in the header | [A track is stuck in Incoming](troubleshooting/incoming-stuck.md) |
| No tags from Beatport or Traxsource, or **Matching catalog** that never ends | [Catalog tagging finds nothing](troubleshooting/no-catalog-match.md) |
| A key or BPM that differs from another app | [My key or BPM differs from another app](troubleshooting/key-or-bpm-differs.md) |
| A sync that finished, but rekordbox shows nothing, or **Read only** | [My sync does not show up in rekordbox](troubleshooting/rekordbox-sync-problems.md) |
| A warning when you first open CueRithm, or an app that closes at start | [My computer blocks CueRithm at first launch](troubleshooting/first-launch-blocked.md) |
| Titles, artists or genres changed that you wanted to keep | [Cleanup changed too much](troubleshooting/cleanup-changed-too-much.md) |

[Fix a problem](troubleshooting/index.md) lists the same pages with the usual cause of each.

## About CueRithm { #about }

CueRithm is independent, open-source software. [About CueRithm](about/index.md) gives the project facts, [Credits and open source](about/credits.md) names the projects it builds on and their licences, and [How CueRithm was made](about/provenance.md) is the owner's account of how Mixed In Key and Lexicon DJ shaped it, and what is and is not claimed.
