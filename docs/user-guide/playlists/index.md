# Build playlists and sets

<p class="lead">Put tracks in the order you will play them, let rules fill playlists for you, check how a set moves from track to track, and find what mixes with what. Playlists live in your CueRithm library and never change an audio file.</p>

A playlist is a list of tracks from **Tracks**. CueRithm has three kinds of item in the **PLAYLISTS** section of the sidebar:

| Kind | Sidebar icon | Who chooses the tracks |
|---|---|---|
| **Playlist** | music note | You, by hand, in an order you control |
| **Folder** | folder | The playlists inside it; opening a folder lists them all, once each |
| **Smart playlist** | lightning bolt | Rules you write; the list updates itself |

The **TOOLS** group under the playlists holds **Playlist tools**, **Compatible tracks** and **Tracklist matcher**. The sections below take you from a first playlist to a finished set.

## Start here

Follow [Create a playlist and add tracks](create-a-playlist.md). In ten minutes you build a folder and a hand-ordered *Warm-up set*, and you meet the controls every other page uses: the playlist bar above the table, drag and drop, manual order and Undo. Then try [Build a smart playlist](build-a-smart-playlist.md) to see rules do the choosing.
