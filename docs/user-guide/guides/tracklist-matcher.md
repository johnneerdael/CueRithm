# Match a reference tracklist

Choose **Tracklist matcher** in the sidebar. Paste an artist/title list or select
a local text or CSV file. Text uses the first ` - ` separator; a line without it
searches by title. CSV can use `artist` and `title` headers, or its first two
columns without headers. Review the parsed values and use **Swap artist and
title** when needed.

Choose same-tag matching or include similar tags, then choose **Find library
candidates**. CueRithm searches prepared, nonarchived local tracks. Each entry
shows up to ten candidates; it states when more were found.

Nothing is selected automatically. Preview the recordings and explicitly choose
the right version for each entry. Similar artist/title tags do not establish
that the mix, edit or audio is identical. Unmatched or unselected entries remain
in a list that can be selected and copied.

Name the playlist and choose **Save selected to playlist**. The playlist follows
the original input order. Selecting the same library track more than once adds
it once, at its first selected position. Use Undo to reverse playlist creation.
If relevant library data changed, refresh matches before saving; an unsuccessful
save does not leave an empty playlist.

Input is limited to 1 MiB, 1,000 entries and 4,096 bytes per field. Matching has a
bounded comparison budget; narrow the input when it reports that limit. Text/CSV
matching does not connect to streaming services or download music.
