# Rename and sort your music files

<p class="lead">Give every file a name you can read and put it in the folder where it belongs, from one naming pattern, after a preview of every change. A first run takes about fifteen minutes and ends with a plan you can undo.</p>

CueRithm can rename files in place, move them into a folder tree sorted by artist, or copy them into a clean library folder and leave the originals alone. Nothing changes until you have read the complete preview and applied it, and every batch goes into a history with Undo.

## Start here { #start-here }

New to organising files? Follow [Rename and sort files into folders](organize-files.md). It previews names for six tracks, copies them into a library folder sorted by artist, checks the result and shows how to reverse it.
