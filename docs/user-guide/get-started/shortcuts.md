# Keyboard shortcuts

Shortcuts are ignored while you type in a text box, a menu or a dialog. On Windows and Linux use ++ctrl++ where macOS uses ++cmd++.

| Shortcut | Action |
| --- | --- |
| ++cmd+f++ | Focus the search box. Works from Settings and Cleanup too. |
| ++cmd+b++ | Collapse or expand the sidebar. |
| ++cmd+a++ | Select every track in the current view or search result (library views only). |
| ++space++ | Play or pause the loaded track. |
| ++arrow-left++ / ++arrow-right++ | Jump one bar back or forward: four beats at the track's saved BPM. Needs a loaded track with a BPM. |
| ++arrow-up++ / ++arrow-down++ | Move the selection in the table. |
| ++enter++ | Play the selected row, with the table focused. |
| ++escape++ | Cancel a playlist drag, or close a menu or dialog. |

## Mouse

| Gesture | Action |
| --- | --- |
| Click a row | Select it. |
| ++cmd++ + click | Add or remove a row from the selection. |
| ++shift++ + click | Select a range. |
| Double-click a row, or press its play button | Load the track and play. |
| Click the waveform | Toggle entire track and 16-second zoom. |
| Click the track overview | Seek. |
| Click a cue button | Seek to that cue. |
| Drag tracks onto a playlist | Add them to an ordinary playlist. |
| Drag a playlist | Reorder it or move it into a folder. |
